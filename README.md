# GESTURA – AI Sign Language Communication Assistant

**Team ID:** 93

**Project ID:** SIC 2.0-08

**Domain:** Accessibility

## Project Overview

GESTURA is an AI-powered Sign Language Communication Assistant designed to bridge the communication gap between individuals with hearing or speech impairments and people unfamiliar with sign language. It leverages Artificial Intelligence and Computer Vision to recognize and interpret sign language gestures and translate them into understandable text and speech.

## Project Objective

- Develop an AI-powered system for real-time sign language recognition.
- Use computer vision and machine learning to identify hand gestures.
- Translate recognized signs into text and speech.
- Enable seamless communication between sign language users and others.
- Promote accessibility and inclusivity through technology.

## Conclusion

GESTURA aims to make communication more accessible by combining artificial intelligence and computer vision. By translating sign language gestures into understandable formats, the project seeks to reduce communication barriers and empower individuals with hearing and speech impairments.
